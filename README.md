# 中文文案人味儿化

一个让中文文案少一点 AI 味、模板感和机器感，同时保留原意与作者习惯的 Codex Skill。

## 这个项目解决什么问题

不少 AI 生成或辅助撰写的中文内容会出现相似的问题：开头空泛，频繁使用“首先、其次、最后”，句式过度工整，结尾又重复总结一遍。文字没有明显语病，却不像真人平时会说、会写的话。

这个 Skill 用于在不改变核心意思和事实信息的前提下，删掉无效套话和重复表达，调整生硬的结构与措辞，让文案更自然、更具体，也更接近原作者本来的语气。

## 核心功能

- 减少 AI 套话、总结腔、书面腔和翻译腔。
- 弱化“首先、其次、最后”等模板化结构。
- 打散过度工整的排比和机械句式。
- 删除没有实际信息量的重复表达。
- 保留事实、数字、立场、语气强弱和作者习惯。
- 根据短视频口播稿、文章或日常表达调整改写方式。
- 原文已经自然时少改或不改，不为了“人味”制造错别字和病句。

## 适合哪些人

- 需要修改短视频口播稿的创作者。
- 希望文章更自然、更耐读的作者和编辑。
- 经常使用 AI 辅助写作，但不喜欢模板腔的用户。
- 想让社交媒体、工作沟通或日常表达更像自己的人。

## 安装方法

先下载本项目并进入项目目录，然后选择复制或软链接到 Codex Skills 目录。

复制安装：

```bash
mkdir -p ~/.codex/skills/zh-copy-humanizer
cp SKILL.md ~/.codex/skills/zh-copy-humanizer/
cp -R agents ~/.codex/skills/zh-copy-humanizer/
```

软链接安装，适合继续在当前仓库中维护：

```bash
mkdir -p ~/.codex/skills
ln -s "$(pwd)" ~/.codex/skills/zh-copy-humanizer
```

如果目标位置已经存在同名目录或链接，请先确认其内容，不要直接覆盖。安装后重新打开 Codex 或新建任务，让 Skill 被重新发现。

## 使用方法

在 Codex 对话中显式调用 Skill，并粘贴需要处理的中文文案：

```text
使用 $zh-copy-humanizer 修改下面这段文案，保留原意和事实信息：

（在这里粘贴文案）
```

也可以补充用途、受众、长度和希望保留的表达：

```text
使用 $zh-copy-humanizer 把下面这段内容改成自然的短视频口播稿。
保留所有数字，控制在 300 字以内，不要增加互动话术：

（在这里粘贴文案）
```

## 使用示例

### 使用前

> 在这个信息快速发展的时代，我们每天都会接触到大量不同类型的内容。如何提高自己的学习效率，已经成为很多人关注的问题。
>

>
> 总的来说，真正高效的学习并不是一味追求投入更多时间，而是找到适合自己的节奏和方法。只有不断优化自己的学习方式，才能在有限的时间里获得更好的成长。

### 使用后

> 每天都会接触到大量信息，怎么学得更高效，也成了很多人关心的问题。
>
> 想避免盲目学习，得先弄清楚自己的目标。目标明确以后，再根据实际情况安排学习计划，把时间用在真正重要的内容上。学习过程中也要及时复盘，看看哪些方法有效、哪些地方需要调整。
>
> 高效学习并不是一味增加投入时间。找到适合自己的节奏和方法，并在实践中不断优化，才能在有限的时间里获得更好的成长。

实际输出会受到原文、上下文和模型版本影响，不要求与示例逐字一致。

## 注意事项

- 本项目用于改写表达，不负责核实原文事实。
- Skill 不应自行补充案例、数据、观点或营销承诺。
- 对专业、法律、医疗、金融等内容，改写后仍应由相关专业人员审核。
- 改写结果不保证完全消除所有模型特征，建议结合具体语境进行人工判断。
- 如果原文已经自然，输出可能只做轻微调整，甚至保留原文。
